# Nivash P. — Digital Marketing Portfolio

## Included
- Responsive single-page portfolio
- India-only location wording (no Chennai / remote wording)
- Clickable project cards linking to:
  - Madhura Auto Consulting — https://madhura-auto-consulting.odoo.com/
  - Dzine House — https://dzinehouse.vercel.app/
  - DigitalGrowthTamil — https://digitalgrowthtamil.com
- Separate `assets/images/` folder for profile, site icon, project images, and certificate image
- Temporary profile image in the header
- `assets/Nivash-P-Resume.pdf` placeholder resume file
- Google Digital Unlocked certificate; Udemy certification removed

## Replace your photo
Replace `assets/images/profile-placeholder.svg` with your own profile image and update the `src` in `index.html` if you use a different filename/extension.

## Replace the resume
When your resume is ready, replace `assets/Nivash-P-Resume.pdf` with your real PDF using the same filename. The **Download Resume** button is already connected to that file.

## Deploy
Upload the complete folder to GitHub, including the `assets` folder and all its files, then deploy the repository on Vercel.
