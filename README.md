# Nivash P. - Digital Marketing Portfolio

A responsive HTML/CSS/JavaScript portfolio designed for GitHub + Vercel.

## Files
- index.html — main webpage
- style.css — all styling
- script.js — mobile menu, active navigation and year
- assets/ — place your resume and profile image here

## Run locally
Open `index.html` in a browser.

## GitHub + Vercel
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Push/commit the files.
4. Import the GitHub repository into Vercel.
5. Framework Preset: Other.
6. Build Command: leave empty.
7. Output Directory: leave empty.
8. Deploy.

## Personalize
- Replace the NP profile placeholder with your own photo.
- Add your PDF resume at `assets/Nivash-P-Resume.pdf`.
- Update the Resume button in `index.html` to `assets/Nivash-P-Resume.pdf`.
- Replace the GitHub URL with your actual GitHub profile.
- Add real project screenshots/links when your projects are ready.
